# 本地开发环境准备

本文档记录本项目在本地 IDE（IntelliJ IDEA）中的运行环境配置步骤，供开发调试使用。

## 环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 17 | 本项目基于 Java 17 |
| Maven | 3.8+ | 依赖管理 |
| MySQL | 5.7 / 8.0 | 主数据库，库名 `qihang-erp` |
| Redis | 5.0+ | 缓存与分布式锁 |

## 启动步骤

1. **初始化数据库**：执行 `docs/qihang-erp.sql` 创建库表与初始数据；
2. **配置数据库连接**：修改 `erp-api/src/main/resources/application.yml` 中 `spring.datasource` 的用户名密码；
3. **配置大模型 API**：
   ```yaml
   spring:
     ai:
       deepseek:
         api-key: ${DEEPSEEK_API_KEY}
   ```
   推荐使用环境变量注入密钥，避免明文提交仓库；
4. **启动 Redis** 后启动 `erp-api` 主服务；
5. 前端（`vue3` 目录）执行 `npm install && npm run dev`。

## 注意事项

- 数据库密码、API Key 等敏感配置请使用环境变量或本地未跟踪文件保存，不要提交到 Git；
- 本地构建产物（`target/`、`node_modules/`）已由 `.gitignore` 忽略。
