## 三、订单状态机设计

### 3.1 支持的订单状态

| 状态码 | 状态名称 | 描述 |
|-------|---------|------|
| 0 | NEW | 新订单 |
| 1 | PENDING_SHIPMENT | 待发货 |
| 2 | SHIPPED | 已发货 |
| 3 | COMPLETED | 已完成 |
| 11 | CANCELLED | 已取消 |
| 12 | REFUNDING | 退款中 |
| 13 | CLOSED | 已关闭 |
| 21 | PENDING_PAYMENT | 待付款 |
| 22 | LOCKED | 锁定 |
| 29 | DELETED | 已删除 |
| 101 | PARTIAL_SHIPPED | 部分发货 |

### 3.2 关键状态迁移规则

#### ✅ 合法迁移 (已通过测试)

```
待付款(21)    → 新订单(0)、已取消(11)、已关闭(13)
新订单(0)     → 待发货(1)、已取消(11)、退款中(12)
待发货(1)     → 已发货(2)、部分发货(101)、已取消(11)、退款中(12)
部分发货(101) → 已发货(2)、退款中(12)
已发货(2)     → 已完成(3)、退款中(12)
已完成(3)     → 退款中(12)  # 售后退款
退款中(12)    → 已关闭(13)、待发货(1)、已发货(2)
锁定(22)      → 待发货(1)、已取消(11)
```

#### ❌ 非法迁移 (已阻止)

```
待发货(1)  → 已完成(3)    # 必须先发货
新订单(0)  → 已发货(2)    # 必须先确认
已完成(3)  → 待发货(1)    # 不能回退
已取消(11) → 待发货(1)    # 已取消不能恢复
```

### 3.3 需要人工审批的操作

```java
待发货(1) → 已取消(11)     // requiresApproval = true
锁定(22)  → 已取消(11)     // requiresApproval = true
```

## 四、售后状态机设计

### 4.1 支持的售后状态

| 状态码 | 状态名称 | 描述 |
|-------|---------|------|
| 0 | APPLIED | 售后申请 |
| 1 | CLOSED | 售后关闭 |
| 2 | PROCESSING | 售后处理中 |
| 3 | REFUNDING | 退款中 |
| 4 | SUCCESS | 售后成功 |
| 5 | PENDING_USER | 待用户处理 |
| 6 | PENDING_BUYER_SHIP | 待买家发货 |
| 8 | PLATFORM_PROCESSING | 平台处理中 |

### 4.2 关键状态迁移规则

#### ✅ 合法迁移

```
售后申请(0)      → 售后关闭(1)、售后处理中(2)、待用户处理(5)
待用户处理(5)    → 售后处理中(2)、售后关闭(1)、待买家发货(6)
待买家发货(6)    → 售后处理中(2)、售后关闭(1)
售后处理中(2)    → 退款中(3)、售后关闭(1)、平台处理中(8)、待买家发货(6)
平台处理中(8)    → 退款中(3)、售后成功(4)、售后关闭(1)
退款中(3)        → 售后成功(4)、售后关闭(1)
```

#### ❌ 非法迁移

```
售后申请(0) → 售后成功(4)    # 必须先处理
售后申请(0) → 退款中(3)      # 必须先进入处理中
售后成功(4) → 售后处理中(2)  # 成功后不能回退
售后关闭(1) → 售后处理中(2)  # 关闭后不能重新打开
```

### 4.3 需要人工审批的操作

```java
售后申请(0)   → 售后关闭(1)    // 拒绝售后，需要审批
售后处理中(2) → 退款中(3)      // 同意退款，需要审批
售后处理中(2) → 售后关闭(1)    // 拒绝退款，需要审批
```

## 五、核心API使用示例

### 5.1 校验订单状态迁移

```java
@Autowired
private OrderStateMachine orderStateMachine;

// 方式1: 直接校验 (返回boolean)
boolean canTransition = orderStateMachine.canTransition(1, 2); // 待发货 -> 已发货
if (canTransition) {
    // 执行状态更新
    order.setOrderStatus(2);
}

// 方式2: 使用校验器 (抛异常)
try {
    TransitionValidator.validateOrder(
        orderStateMachine,
        order.getOrderId(),
        order.getOrderStatus(),  // 当前状态: 1 (待发货)
        2                        // 目标状态: 2 (已发货)
    );
    // 校验通过，执行状态更新
    order.setOrderStatus(2);
} catch (IllegalStateTransitionException e) {
    // 非法状态迁移，记录日志或返回错误
    log.error("订单状态流转不合法: {}", e.getMessage());
}
```

### 5.2 获取可迁移的状态列表

```java
// 获取订单当前状态可迁移到的所有目标状态
List<OrderState> availableStates = orderStateMachine.getAvailableTransitions(1); // 待发货
// 返回: [SHIPPED(2), PARTIAL_SHIPPED(101), CANCELLED(11), REFUNDING(12)]

// 用于前端展示 "可执行操作" 按钮
for (OrderState state : availableStates) {
    System.out.println(state.getCode() + " - " + state.getDescription());
}
```

### 5.3 检查是否需要审批

```java
boolean needsApproval = orderStateMachine.requiresApproval(1, 11); // 待发货 -> 取消
if (needsApproval) {
    // 触发审批流程
    approvalService.createApprovalRequest(orderId, "取消订单");
} else {
    // 直接执行
    order.setOrderStatus(11);
}
```

## 八、与现有代码的集成方式

### 8.1 在Service层使用 (推荐)

```java
@Service
public class ShopOrderServiceImpl implements ShopOrderService {
    
    @Autowired
    private OrderStateMachine orderStateMachine;
    
    public void updateOrderStatus(Long orderId, Integer newStatus) {
        ShopOrder order = getById(orderId);
        
        // 校验状态迁移合法性
        TransitionValidator.validateOrder(
            orderStateMachine,
            order.getOrderId(),
            order.getOrderStatus(),
            newStatus
        );
        
        // 检查是否需要审批
        if (orderStateMachine.requiresApproval(order.getOrderStatus(), newStatus)) {
            // 触发审批流程 (第一阶段Week2-3实现)
            createApprovalRequest(order, newStatus);
            return;
        }
        
        // 执行状态更新
        order.setOrderStatus(newStatus);
        updateById(order);
    }
}
```

### 9.3 Service层改造示例

```java
@Service
public class ShopOrderServiceImpl extends ServiceImpl<ShopOrderMapper, ShopOrder> 
    implements ShopOrderService {
    
    @Autowired
    private OrderStateMachine orderStateMachine;
    
    @Override
    public boolean updateOrderStatus(Long id, Integer newStatus) {
        ShopOrder order = getById(id);
        
        // 状态机校验
        TransitionValidator.validateOrder(
            orderStateMachine,
            order.getOrderId(),
            order.getOrderStatus(),
            newStatus
        );
        
        // 乐观锁更新
        LambdaUpdateWrapper<ShopOrder> updateWrapper = new LambdaUpdateWrapper<>();
        updateWrapper.eq(ShopOrder::getId, id)
                     .eq(ShopOrder::getVersion, order.getVersion()) // 乐观锁
                     .set(ShopOrder::getOrderStatus, newStatus)
                     .set(ShopOrder::getVersion, order.getVersion() + 1);
        
        return update(updateWrapper);
    }
}
```
