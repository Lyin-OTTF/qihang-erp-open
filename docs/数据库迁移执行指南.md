# 数据库迁移执行指南

## 步骤1：备份数据库（重要！）

在执行迁移前，请先备份数据库：

```bash
# 方式1: 使用MySQL客户端
mysqldump -h127.0.0.1 -uroot -p1234 qihang-erp > backup_before_version_migration_$(date +%Y%m%d).sql

# 方式2: 使用Navicat/DBeaver等图形化工具导出
```

## 步骤2：执行迁移SQL

### 方式A：使用MySQL命令行

```bash
mysql -h127.0.0.1 -uroot -p1234 < docs/sql/migration_v4.1.1_add_version_columns.sql
```

### 方式B：使用Navicat/DBeaver/DataGrip

1. 打开SQL脚本文件：`docs/sql/migration_v4.1.1_add_version_columns.sql`
2. 连接到 `qihang-erp` 数据库
3. 执行完整脚本
4. 查看最后的验证查询结果

## 步骤3：验证迁移结果

执行以下SQL确认version字段已添加：

```sql
-- 查看所有表的version字段
SELECT
    TABLE_NAME AS '表名',
    COLUMN_NAME AS '字段名',
    COLUMN_TYPE AS '字段类型',
    COLUMN_DEFAULT AS '默认值',
    COLUMN_COMMENT AS '备注'
FROM
    information_schema.COLUMNS
WHERE
    TABLE_SCHEMA = 'qihang-erp'
    AND COLUMN_NAME = 'version'
    AND TABLE_NAME IN (
        'oms_shop_order',
        'erp_o_order',
        'oms_shop_refund',
        'erp_o_after_sale',
        'erp_goods_inventory'
    )
ORDER BY TABLE_NAME;
```

**预期结果**：应该看到5行记录，每张表都有version字段

## 步骤4：测试乐观锁功能

执行以下SQL测试乐观锁：

```sql
-- 假设订单ID=1存在
-- 第一次更新（应该成功）
UPDATE oms_shop_order
SET order_status = 1, version = version + 1
WHERE id = 1 AND version = 1;

-- 查看影响行数
SELECT ROW_COUNT(); -- 应该返回1

-- 第二次使用旧version更新（应该失败）
UPDATE oms_shop_order
SET order_status = 2, version = version + 1
WHERE id = 1 AND version = 1; -- version已经是2了

-- 查看影响行数
SELECT ROW_COUNT(); -- 应该返回0，说明乐观锁生效
```

## 步骤5：更新实体类（如果使用MyBatis-Plus）

在 `ShopOrder.java` 和 `ShopRefund.java` 中添加 `@Version` 注解：

```java
/**
 * 乐观锁版本号
 */
@Version
private Integer version;
```

## 回滚方案

如果迁移出现问题，执行以下SQL回滚：

```sql
ALTER TABLE `oms_shop_order` DROP COLUMN `version`;
ALTER TABLE `erp_o_order` DROP COLUMN `version`;
ALTER TABLE `oms_shop_refund` DROP COLUMN `version`;
ALTER TABLE `erp_o_after_sale` DROP COLUMN `version`;
ALTER TABLE `erp_goods_inventory` DROP COLUMN `version`;
```

## 预计影响

- **停机时间**: 0秒（在线DDL）
- **执行时间**: 5-10秒（取决于数据量）
- **磁盘空间**: 每张表增加 ~4MB（100万行数据）
- **性能影响**: 无（索引不受影响）

## 注意事项

1. ✅ 建议在**业务低峰期**执行
2. ✅ 执行前确保有**数据库备份**
3. ✅ MySQL版本需 >= 5.6（支持在线DDL）
4. ⚠️ 如果表数据量>1000万，建议使用pt-online-schema-change工具
